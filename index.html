PROJECT 01 / 2025.11 — 2025.12

Woooly / 우울이

Dynamic psychological counseling patient simulation chatbot

Problem

일반적인 챗봇은 상담 관계가 깊어지는 과정에서 환자의 방어적 반응과 변화하는 태도를 충분히 표현하기 어려웠습니다.

Approach

KMI 데이터셋을 바탕으로 상담 단계에 따른 Synthetic Phase-Shifting 데이터를 구성하고, SFT와 Offline DPO를 연결했습니다.

Implementation

Unsloth와 4-bit QLoRA로 학습 비용을 줄이고, K-PatientBench로 Resistance와 Change Talk를 평가했습니다. vLLM 서버와 Next.js UI를 연결해 실제 상담 흐름을 시연했습니다.

Outcome

SFT 대비 DPO 모델의 상담 행동을 정량 비교하고, Hugging Face에 모델을 공개했습니다.

GitHub ↗Hugging Face ↗Demo ↗

PROJECT 02 / 2025.04 — 2025.10

Sign-language Counseling System

An end-to-end counseling system connecting sign language and text

Problem

수어 사용자가 상담 과정에서 겪는 의사소통 장벽을 줄이고, 수어 영상에서 상담에 필요한 의미와 감정을 추출해야 했습니다.

Role

프로젝트 리더로서 모델 학습과 파인튜닝을 담당하고, 영상 입력부터 상담 응답까지의 전체 파이프라인을 설계했습니다.

Implementation

RTMPose·MMPose로 키포인트와 RGB 특징을 추출하고, PGF-GCN과 Uni-Sign 구조로 시공간·위상 정보를 모델링했습니다. Llama-3-Open-Ko-8B는 LoRA와 4-bit QLoRA로 파인튜닝했습니다.

Optimization

24GB GPU 환경에서 병렬 포즈 추출과 파라미터 효율적 학습을 적용해 처리 안정성과 실험 가능성을 높였습니다.
